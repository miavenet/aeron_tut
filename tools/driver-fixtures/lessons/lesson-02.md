# Synthetic lesson 2 — museum labels

Synthetic driver fixture, not an Aeron lesson. Budget: 6 minutes.

### CARD F2-P · Before you learn
Q: Guess: should a museum label identify an exhibit or an entire building?
Key:
- In this fictional museum, the label identifies one exhibit.

### CONCEPT F2-C · The idea
In this fictional museum, each exhibit has one distinct label.
Worked: labels A and B name separate exhibits; a building can contain both.
Elaborate: Why does a building name alone leave the exhibit ambiguous?

### CARD F2-F · Try it
Q: Type the exact label for the first exhibit: A or B.
Key:
- A

### CARD F2-R · Recall
Q: State what a label identifies in the fictional museum.
Key:
- One exhibit, rather than the entire building.

### CARD F2-T · Apply
Q: Two boxes occupy the same shelf. Apply the fictional label rule to let a visitor select one box.
Key:
- Give each box a distinct label; the shared shelf name cannot select one box.
